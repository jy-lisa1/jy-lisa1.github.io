# Welcome to my personal site!

A digital gallery showcasing my artwork, built with love using React.

## About

This site is a personal portfolio where I share my creative work across different mediums. 
It serves as a place to explore my paintings, block prints, and other handmade pieces.

## Artwork Categories

- **Paintings** - Oil, acrylic, and the occasional gouache painting. My "main" creative hobby!
- **Block Prints** - Hand-carved and printed artwork
- **Other** - Miniatures, felting projects, and other creative works
